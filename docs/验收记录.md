# 验收记录

在 Windows、Node.js 24、Chrome 环境验证。正式示例为北科大 30 页、丽水学院 30 页，根目录 HTML 是可继续编辑的源稿，output 为正式 PDF/PPTX，ect 为截图及中间产物。

## v0.1.3：单行字段、中文标点及原生项目符号

- 脚注、来源、页码与作者姓名强制单行；封面／尾页和过渡页使用父区域宽度，标题只保留手动分行。网页实际为单行的段落也关闭原生自动换行，真正跨行的正文保留自然排版。
- 页面、模块／分组、分项、图标题、目录及时间轴标题在HTML和PPTX共用单行／手动分行政策；超宽在网页和服务端同时提示调整，专项测试验证模块标题的手动两行与超宽拦截。
- 文本和富文本run明确指定zh-CN；段落补齐中文断行与悬挂标点属性，并消除重复段落属性。逐段列表导出为原生项目符号和悬挂缩进，保留普通段与列表混排、不同符号以及局部加粗／颜色。
- “插入”收起宽度固定88px，展开保留完整选项；1920px文字编辑工作台的工具栏恢复单行，窄屏仍允许自然换行，控件不挤出屏幕。说明截图已重取。
- `tests/pptx-text-flow.mjs`覆盖单行字段、手动标题分行、中文段落属性、可点击来源、原生列表／普通段混排和多行正文；A3背景、过渡页标题、14项E2E、两校布局及参考快照回归通过。
- 本机PowerPoint实际打开并渲染两份正式PPTX，共60页、1360个文本对象；读取实际文本行，未发现仅标点占一行的情况。另渲染5页专项文件，确认原生符号及局部粗细颜色。这些自动测量不替代使用者对目标环境的人工逐页审核。
- 原有30页内容与几何结构保留；两校HTML、四份正式导出和说明插图同步更新，三份reference HTML快照不改。

## v0.1.2：可编辑履历与计划、批量文字格式及PPTX修复

- 作者简介恢复固定浅底身份卡与原有经历分组，右侧改为履历横线表及含两个子区域的无框线表格。可独立增减子区域、行、列，按名称用箭头排序及删除，单元格格式与内容随所属分组一起保存。
- 阶段总结使用三张A2卡片、20／18／16pt层级，下一步计划保留14pt纯表格与独立C1讨论区。标题可隐藏而不删除数据；A/C1卡片支持紧凑内边距，仍检查真实截断及遮挡。
- 插入入口合并为下拉菜单，多个分离空白区域先预览选择；固定身份卡纳入占用。编辑文字时可删除当前子区域或整个模块，提供范围确认和撤销。
- 表格与字符字号支持10／12／14／16pt。作者表格默认正文14pt、字段标题16pt；手动固定表格字号不自动缩回小档位。Shift多选文字块／单元格，可统一改字号、粗细、颜色和间距，单次批量操作可整体撤销，保存重开保留。
- 时间轴隐藏模式改为并列图文卡片，事件短名置于顶部，年份、箭头、圆点及连线隐藏但不丢失数据。
- A3标题容器显式作为原生深色形状导出。页尾总结使用整条内部宽度并关闭原生自动换行，保持16pt，不因Office字形差异将句号推到下一行。
- `tests/structured-editing.mjs`与`tests/multi-block-formatting.mjs`验证上述真实控件、针对性删除／排序、选择区域、批量格式和离线往返。原有14项E2E与局部富文本回归通过。
- 两校60页布局无溢出，两份30页PDF为960×540pt；两份PPTX均验证6处A3背景及9条单行总结，并保留原生文字和表格。导出结果仍需在实际演示软件人工检查字体及播放效果。

## 重要边界

特殊页面复用原北科内容快照及局部 CSS，文字、头像与 LaTeX 可改，结构由 AI 调整；普通页面继续使用模块编辑。PPTX 普通文字和表格单元格可编辑，公式、复杂装饰及特殊页背景为独立图片。未声称原生 Office 公式。

自动检查不替代最终阅读。导出的 PPTX 还应在实际汇报电脑上核对字体、视频和放映行为；本轮未通过桌面 PowerPoint 进行人工逐页验收。自动检测显示器暂未实现，采用手动拖动观众窗口。

## 复验命令

先启动服务，再按需执行：

```powershell
npm.cmd test
node tests/e2e.mjs
node tests/editor-and-presets.mjs
node tests/notes-presenter.mjs
node tests/media-layout.mjs
node tests/pptx-headings.mjs
node scripts/check-example.mjs --screenshots
node scripts/check-example.mjs --lishui --screenshots
node scripts/check-widows.mjs
node scripts/check-widows.mjs --lishui
```

所有检查产物写入 ect，不与正式交付文件混放。

新增目录与窄框检查：node tests/toc-and-narrow.mjs，覆盖目录删除／恢复／自定义、附录默认排除及可选纳入、离线保存、B1/B2/B3 窄框与导出。


公式编辑专项：node tests/formula-editor.mjs。覆盖原矢量公式／修改后公式／普通公式模块，预览状态双击、复制源码、空值与语法错误保留输入、确认与取消、离线保存重开。


过渡页专项：node tests/pptx-transitions.mjs 直接检查 PPTX XML，验证章节名称和章节号 wrap=none、宽文本框、无自动缩字、手动分行数量准确；超过安全宽度时拒绝导出并提示手动处理。


学校共用母版专项：node tests/school-variants.mjs 验证两校均为30页、页面类型和模块几何结构一致、丽水主题单色、媒体均为本校素材；reference三份HTML的哈希与截图完整。学校资料来源和照片说明见 assets/丽水学院/manifest.json。

目录清理回归：从空 ect 目录启动并运行模型、E2E、富文本与预设、公式、目录与窄框、媒体、备注与放映、PPTX 章节标题与正文标题、导航、控件及十种文字样式测试。两校全部60页无版面错误，正式HTML/PDF/PPTX已重新生成。清理项及保留依据见[项目结构与清理记录](项目结构与清理记录.md)。

选区与内容专项：`tests/selection-formatting.mjs`使用真实控件点击验证局部粗细、颜色、字号，同块混合普通段与列表，12pt段后距、离线重开，以及公式用原LaTeX再次确认后无溢出。`tests/content-contracts.mjs`验证index离线提示、原版总结的内缩和14pt计划表、只有顶部表头深底、正文首列浅底、实验表首列分隔线、表注可修改和删除。两校短尾行检查均为空；60页版面检查均无溢出，三份reference快照哈希已核对。

独立文本块与紧凑编辑：`tests/editor-refinements.mjs`验证选区读取14/16pt、当前行距和不同段后距，直接改14pt、混合值回显，圈定的深底白字／白底深字文本块吸附网格，靠近页尾总结仍能完整显示；普通表格统一最小行高／上下内边距，成熟参考文献表上下内边距，以及离线保存重开。真实超量文字仍会产生排版错误。专项PPTX另检查两种底色为独立形状，正文仍为原生可编辑文本。
