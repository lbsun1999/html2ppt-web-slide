文本块组件说明#

依据用户提供的《文本块样式规范.pdf》，并纳入后续修订：C2 内部不再提供 A1，B1 折角右缘与白框左边线对齐。

复用方式#

src/text-styles.js 为十种样式的注册与渲染入口，text-styles.css 定义视觉规则；src/style-picker.js 提供编号选择器和预览。src/render.js、工作台、离线 HTML 和导出统一调用这些组件。

运行 npm run build:styles 从共享代码生成独立的 文本块样式展示.html。不将 PDF 截图当作组件，也不在展示页重复维护另一套 HTML 样式。改变组件后重新生成展示页。

字体与结构#

  • 默认标题 30px≈18pt，正文 26.67px≈16pt，正文行高 1.55，不随拥挤自动缩小。
  • 新项目标题主色按示例使用 #005894，正文为黑色。定制主题后组件跟随主题色与正文颜色，不覆盖用户显式设置。
  • C2 模块大标题 33.33px≈20pt，高于内部 18pt 分项标题。内部背景透明，仅靠标题和细线分组。
  • C3 正文 16pt，加粗子标题同为 16pt，注释 14pt。可分别开关并直接编辑，保持独立字段。
  • C3 序号使用 Times New Roman、20pt、700 粗体（1600px 标准宽屏画布约 33.33px），不使用 Georgia 等替代装饰字体。
  • 装饰标题宽度可调，长标题换行后仍通过模块测量检查可用高度。
  • 无序列表使用原有正文编辑机制，每个显式换行代表一项。

结构与数据兼容#

默认、A1、A2、A3 继续使用 plain、unified、cards、band 内部 ID。B1、B2、B3 为 ribbon、capsule、arrow；C1、C2、C3 为 note、group、numbered。

布局字段包括 headerWidth（标题装饰宽度百分比）、groupTitle（C2 模块大标题）、numberStart（C3 起始序号）。C3 的子标题、注释及显示开关放在各 parts 中。未显示的内容保持在数据内，样式切换不会删除用户文字。

C2 的 innerStyle 在读入旧数据时归一化为 plain；渲染器也固定使用默认分组，即使历史数据仍带 unified 也不会绘制浅底。界面不再提供内部样式选择。

B1 对齐#

组件局部坐标中，标题左缘位于 x=8，深色三角折角宽 14px，右缘为 x=22；白底文字框的左边线也位于 x=22。正文相对这条边线再留出内边距。改变标题宽度时只调整右端，折角与左边线保持固定。

导出#

普通卡片、分隔线和文字仍输出为独立的原生 PPTX 对象。折角、胶囊、箭头、渐变边线与阴影通过独立 SVG 装饰绘制，导出时只栅格化纯装饰，文字不包含在装饰图片中。

导出按 DOM 绘制顺序排序背景、装饰、文字和媒体，避免后添加的白底装饰遮盖 C2 内部分组或标题。PDF 使用同一浏览器布局。

文字精修与间距#

正文可按当前文字块独立设置列表，模块统一设置仍保留。选区支持加粗、主题色／原色／自选色及 14／16pt；行距输入后失焦应用。段间距至少 6pt（10 画布 px），与行距分开控制。C3 下层为同形浅色梯形，向右偏移 16px。

选区改变时，工具栏自动读取当前字号、行距、段后距、列表、颜色和粗细，不沿用历史操作值；多种值显示“混合”。输入控件保持焦点时不会被自动回显打断。独立文本块使用textBox与boxTone字段，单个正文区域可切深底白字／白底深字，不归入C1备注样式。

模块间建议12px，紧凑时可缩小；真实遮挡、越界及文字截断才报错。文字块上下内边距可适度自适应，但不自动压缩字号或行距。
