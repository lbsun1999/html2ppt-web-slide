版本记录#

v0.2.0 · 2026-10-29#

这是相对 v0.1.0 的正式升级。本版本已经形成可以独立分享、扩展和持续迭代的完整工作台。v0.1.1–v0.1.4 仅为开发过程节点，不作为正式版本保留。

制作与编辑#

  • 支持大纲导入、章节／目录同步、页面复制排序和模块化编辑。
  • 支持文字选区格式、段落对齐、表格批量编辑、LaTeX 公式及 SVG／图片／视频媒体。
  • 提供北科蓝、北科红和丽院青三套可增量扩展的模板包。

排版与对齐#

  • 提供参考线平移、单边拉伸、多选等距和环形组合。
  • 使用紧凑的主题色选项卡和图形按钮。
  • 显示网格时参考线自动吸附，关闭网格时自由拖动。
  • 多子区域参与等距计算，并固定外侧边界、平均内部间隙。

放映与交付#

  • 全屏放映支持总览、缩放和拖动查看。
  • 演讲者视图提供独立观众窗口、备注隔离、同步翻页和自动切换备注。
  • 支持保存／另存 HTML，以及指定路径导出 PDF 和可编辑 PPTX。

文档与质量#

  • 提供离线 HTML 文档站、AI 协作 SKILL、模板扩展说明和交互参考示例。
  • reference/navigation.html 内置时间轴与高级对齐练习页。
  • 全量自动检查覆盖编辑、放映、主题、参考库及 PDF／PPTX 导出关键路径。
导出的 PPTX 已尽量保留可编辑对象与原版式，但仍须人工逐页复核字体替代、局部颜色、标点断行和最终投影效果。
