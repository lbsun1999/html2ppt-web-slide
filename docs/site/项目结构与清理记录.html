项目结构与依赖#

运行依赖及用途#

文档大纲由src/outline.js解析、映射和更新数据，src/outline-import.js提供制作中可反复打开的管理弹窗。src/table-text.js负责当前表格的制表符文本往返与批量修改，src/table-text-editor.js显示金色Tab间隔并同步滚动；段落对齐继续复用src/rich-text.js，不增加编辑器分支或运行依赖。配套大纲示例位于docs/大纲示例.md。

v0.1.2未增加运行依赖。editable-layouts.js负责作者／计划预设，profile-card.js保留固定身份卡，table-blocks.js负责履历及分组表格，text-block-selection.js管理临时多选；专用样式集中在structured-layouts.css并由共享CSS加载器统一内嵌。删除已不使用的旧预设辅助函数，测试及中间文件仍放ect，不进入分享包。

依赖实际用途入口
esbuild工作台启动时打包浏览器脚本；生成独立 HTMLserver.mjs、scripts/build-document.mjs
exceljs读取 Excel 工作簿与合并单元格server.mjs
katexLaTeX 语法校验、预览和公式渲染src/formula.js
playwrightPDF 导出及 PPTX 对象测量、媒体截图server.mjs
pptxgenjs写入可编辑 PPTXserver.mjs
jszip规范PPTX段落XML，补全中文断行规则并保留原生列表属性src/server/pptx-typography.mjs

v0.1.3将此前已被依赖树使用的JSZip显式列为直接依赖，用于PPTX段落规范化。以上六项均由实际功能引用，不删除或误移到仅开发依赖。node_modules 是安装产物，不手动裁剪其内部文件；分享源码时可不打包，由 npm ci 恢复。独立 HTML 的浏览、编辑与放映不读取 node_modules。

目录用途#

位置用途
templates/按版式族和模板包管理的正式HTML、素材、清单与导出快照
src/编辑器、渲染、模型与学校变体
src/server/服务端必需的学校资源和共享样式加载
scripts/生成、检查、预览及清理等维护命令
reference/两份工作台参考HTML及截图／哈希；blank-template提供空白模块起点
docs/说明、原始样式规范和正式预览图
tests/回归测试；fixtures/ 为固定测试视频，不参与默认示例
ect/、test-results/可再生检查产物，清理后按需重建

根目录保留使用说明、技能入口及运行入口；src存放模型与编辑逻辑，docs与reference分别承担说明和已确认参考。正式HTML、学校素材和对应PDF/PPTX全部进入各自模板包，避免学校成稿与公共运行时代码混放。

GitHub包含公共源码、独立模板包、说明插图和reference；不包含node_modules、ect、test-results、本地备份和日志。依赖用package-lock.json锁定并通过npm ci恢复。发布前检查所有README本地链接可到达，避免移动模板后留下失效的HTML、素材或导出链接。

清理后验证#

从空临时目录重新启动服务、生成两校正式 HTML/PDF/PPTX，并验证模型单元测试、Excel 导入、媒体上传、HTML 离线保存、公式编辑、富文本编辑、目录增删、窄文本框、备注及放映操作。PPTX 另查章节标题禁止自动换行和正文标题主题色。

两校共60页的版面检查均无溢出错误。早期reference曾由五份精简为三份；当前进一步整理为example-project.html和blank-template.html两份工作台参考，文字块样式改由根目录一屏速览页承担。空白模块模板由构建脚本生成并单独校验目录、媒体、表格、时间轴、公式和作者附录。入口依赖图确认顶层源模块均可达；timeline、sidebar-pages和page-operations均由实际运行入口引用，没有新增运行依赖。

额外回归发现并修正两处旧问题：文字样式展示页的卡片高度不足，自定义列表符号的旧 CSS 覆盖了实际符号。十种文字样式、符号显示、撤销重做与离线导出均重新验证。发布整理时已删除examples空目录，其中没有运行文件或资源引用。

维护命令#

npm.cmd start
npm.cmd test
npm.cmd run test:e2e
npm.cmd run build:examples
npm.cmd run clean

build:examples 更新templates/template-1/内的北科蓝与北科红；build:lishui更新丽院青。追加 -- --export 可把正式PDF/PPTX写入对应包的output/，需要本地服务运行。clean 仅清理 ect 和 test-results，不处理模板包、reference或依赖目录。正式材料不要放在临时目录。

运行编辑器只需 Node.js 20.10+、Chrome/Edge 和上述 npm 依赖。Python/Pillow 仅供部分检查、拼图工具使用；普通用户不必安装。

当前模板包结构#

templates/template-1/包含ustb-blue、ustb-red和lishui-cyan三个模板包。每个包都自带template.html、template.json、README、assets/和output/，可以单独复制和打开；公共运行时仍只有一份。

新增同族模板时复制子目录并替换自身数据与素材；新增另一套页面体系时建立新的版式族目录。单纯新增模板不修改src/、不复制公共接口，也不建立长期学校分支。

启动入口拆为保持真实CRLF的ASCII启动.cmd和可记录错误的scripts/start.mjs；Windows不会再依赖含中文的批处理逻辑。SVG、主题色、离线传送与保存路径选择均复用共用接口，未新增运行依赖。
