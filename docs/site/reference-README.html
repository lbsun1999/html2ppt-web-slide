参考示例：完整汇报与空白模块模板#

reference/ 只保留两份可直接打开的工作台 HTML。它们使用当前版本的编辑、放映、保存和导出能力；文字块的快速比较另见根目录 文本块样式展示.html。

示例文件页数主要用途
example-project.html6查看一份科研汇报中封面、内容、表格、媒体与结束页的组织方式
blank-template.html7从空白占位内容开始，练习目录、媒体、表格、时间轴、公式和简历模块

综合示例#

本地打开 example-project.html。六页依次呈现封面、问题背景、方法框架、结果表、图像证据和结束页。真实制作时应替换全部占位材料和数字，并核对来源。

模块样例速览：可直接使用的空白起点#

本地打开 blank-template.html。页面结构如下：

页码页面使用方式
1封面替换标题、汇报人、单位与日期；校徽和组合标志使用占位符
2自动目录从第3–6页的章节名称生成目录卡片及页码范围
3图片与视频双击占位区上传素材，编辑图标题与说明，并保持并列媒体等高
4数据表格修改表头和数据，按需增减行列、调整字号、行高及单元格内边距
5研究进展与里程碑增减、排序阶段，替换年份、事件、图片或视频；也可隐藏时间轴装饰
6公式与符号说明双击修改 LaTeX；公式名称、解释文字和符号表均可编辑
7作者简介附录页，包含身份卡、履历表和无框线信息表；默认不进入目录

第3–6页各自使用手动章节名称，因此目录始终保持四个卡片。第7页的章节编号为“附录”，系统会自动排除；只有用户主动启用“目录包含附录”时才会加入。

文字块速览#

根目录 文本块样式展示.html 用一屏比较默认、A1–A3、B1–B3和C1–C3。A、B系列不显示模块大标题；C1无子标题，C2显示模块大标题并采用两列子区域，C3子标题带序号。该页适合快速选样式，不承担完整工作台示例职责。

截图与维护#

运行 node scripts/build-blank-template.mjs 重新生成空白模块模板；运行 node scripts/preview-reference.mjs 校验两份参考HTML的哈希，并在当前工作台中生成多页预览图。snapshots.json记录参考文件哈希、页数、列数和截图所用的工作台版本。
