文字样式：同屏比较层级与留白#

打开text-styles-example · 原尺寸截图

页码样式重点
1–4默认、A1、A2、A3分段、整体浅底、分立卡片和深色标题
5–7B1、B2、B3折角、圆角与箭头标题
8–10C1、C2、C3补充备注、组合分组与编号步骤

C2内部仅用无底色默认分组。C3适合多个有次序的子区域；普通内容只有一块时，使用默认、A3或B1等无序号样式，避免孤立的“01”。本文件中的单块C3专用于展示组件形态。

导航与时间轴：先看章节，再调整阶段#

打开navigation · 完整工作台原图

目录位于第2页，第3、5、7页是章节过渡。第10页为时间轴，第11页为高级对齐练习，第12页结束。目录从过渡页推导标题、序号及页码范围；移动页面后重新同步，不手工维护页码。

时间轴使用通用的“问题提出、方法演进、实验验证、应用拓展”四阶段，不含学校标识与校园图像。深色年份块、圆点、线段及事件短名统一主题色，卡片及箭头保留浅底。

  1. 左侧选第10页，进入“编辑模块”并点击时间轴；右侧可添加阶段、删除任意阶段或前后移动。支持1–6阶段，建议2–5阶段。
  2. 增减后卡片自动均分宽度，媒体框保持实际等高；年份、事件与说明随对应阶段一起重排。
  3. 切换“编辑文字”，修改年份、事件短名和介绍。双击占位框上传照片或MP4／WebM视频，可调整取景及缩放。
  4. 保存HTML再打开，复查内容、阶段顺序和媒体。长内容应凝练、扩大模块或拆页，不能遮挡箭头及页脚。

左侧支持Ctrl／Shift多选、复制粘贴、拖动排序和选中删除，常用按钮固定在左下角；操作及快捷键见页面管理说明。备注与放映直接参考主项目说明，不再保留单独的备注示例文件。

高级对齐：在练习页直接动手#

打开navigation并选择第11页。“高级对齐与分布练习”有意保留错位、不同尺寸和一个多子区域板块。进入“编辑模块”，选择任一板块并打开“高级对齐与分布”，即可体验：

  • 纵向／横向参考线平移，图形按钮对应贴边或居中。
  • 固定参考线后向左、右、上或下拉伸。
  • 多选板块后执行水平等距、垂直等距或环形分布。
  • 多子区域参与等距计算时，外侧边界保持不变，内部间隙重新平均。

建议先复制第11页，再反复操作；这样可随时回看原始错位状态。
