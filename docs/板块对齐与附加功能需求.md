# 板块对齐与附加功能需求

本说明根据 `板块对齐功能说明.pptx`（10 页）整理，作为实现和验收基线。参考线、选择高亮和辅助线只属于编辑界面，不进入放映、PDF 或 PPTX。

## 1. 高级对齐

- 右侧栏提供“高级对齐与分布”入口，浮动面板不阻断画布操作。
- 五种模式互斥且允许再次点击清空：纵向参考线平移、纵向参考线拉伸、横向参考线平移、横向参考线拉伸、多选分布。
- 每页同时只显示一条参考线。参考线使用主题色虚线，可拖动；按住 `Shift` 时吸附当前网格，否则在正文安全区内自由移动。
- 可显示标尺，也可直接输入参考线坐标。
- 平移支持左／水平中心／右、上／垂直中心／下对齐；拉伸只移动指定边缘，另一边保持不变。
- 会越出安全区、遮挡其他板块或使板块过窄的操作必须拒绝。拉伸后出现内容溢出时保留可编辑状态并显示粗红框。

## 2. 多选与均匀分布

- 多选对象是独立文本块或完整模块。候选项灰显，已选项恢复原色并显示绿色外框。
- 横向或纵向分布时，保持该方向最外侧边界不变，仅平移板块，使净空平均分配，不改变板块尺寸。
- 多子区域模块要展开可见子区域参与间隙计算。因此只选择两个外层模块时，只要其中含多个子区域，内部仍可能重新均分；只有两个模块都各含一个区域时通常保持原位。
- 分布结果若越界或与未选对象重叠，拒绝应用并给出明确提示。

## 3. 环形分布

- 多选板块可直接环形排布；只选一个板块时可指定复制数量。
- 圆心默认取所选内容的几何中心；用户可设置半径、起始角度和结束角度，不自动旋转子板块。
- 确认后生成一个组合模块。组合可整体移动、按固定锚点缩放，内部对象保持相对位置。
- 越出安全区的结果允许暂存，但组合显示粗红框且导出前必须修正。

## 4. SVG 图标扩展

- 在用户明确同意后，AI 可以为板块小标题生成语义明确、风格克制的 SVG 图标。
- 图标有名称，选中对应子区域时在右侧栏显示；支持上传、等尺寸替换、单独隐藏和一键隐藏本页全部图标。
- 隐藏图标后标题和正文自动回流，不留下固定空洞。
- 此功能是可选扩展，不能擅自给所有页面加装饰图标。

## 5. Markdown 行内公式

- 子区域可启用 Markdown 行内公式，使用 `$...$` 标记。
- 编辑文字时保留 LaTeX 源码；预览和放映时渲染为标准公式。
- PDF 始终导出为图像公式。PPTX 导出前可选择：图像公式，或以红色文字保留 LaTeX 源码供人工重建。
- 独立公式页仍优先交给 AI 按材料和页面空间编排；不要把复杂推导强塞进普通文段。

## 6. 内容导航页

- `index.html` 是图文内容导航：首先展示主模板及预览，再链接 README、操作文档、SKILL 和模板扩展说明。
- 综合示例、文本样式、导航／时间轴等测试页面放在末尾，明确标注为参考入口而非主模板。

## 验收原则

1. 同一数据结构在离线 HTML、本地工作台、放映、PDF 和 PPTX 中可持续使用。
2. 对齐操作可撤销；不会静默改变字号、行距或内容。
3. 自动排版只解决几何关系，内容取舍、层级和最终人工复核仍按 `SKILL.md` 执行。
