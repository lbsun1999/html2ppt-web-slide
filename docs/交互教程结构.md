# 交互教程结构

交互教程位于 `templates/template-1/ustb-blue/tutorial.html`。它以北科科技蓝模板为训练场；点击顶部“开始教学”后，先进入全屏教程目录。

![交互教程全屏目录](images/tutorial-catalog.png)

目录提供两种学习方式：

- **完整教学流程**：从主题换肤开始，按原有顺序连续完成 12 个板块，板块之间自动衔接。
- **分项练习**：直接进入任意板块。进入第 N 项时，系统会在后台重建前 N−1 项完成后的标准状态，再直接显示该板块的第一步。

分项通关后显示居中的奖杯汤姆结算弹窗，右下角返回教程目录；分项结算不播放完整教程中的杰瑞／汤姆语音或最终欢呼。

![分项通关结算页](images/tutorial-section-settlement.png)

| 序号 | 教程大项 | 练习页面或入口 | 核心内容 |
| --- | --- | --- | --- |
| 00 | 开始 | 全屏教程目录 | 选择完整流程或单个板块；查看本次进度 |

| 02 | 大纲教学 | 文档大纲 | 粘贴三级大纲，生成章节、目录及页面标题 |
| 03 | 页面设置 | 页面信息与备注练习 | 修改标题、章节、页首句、来源、页尾总结和备注 |
| 04 | 模块编辑 | 空白正文与卡片排版 | 插入卡片，调整网格、位置、尺寸、锚点、样式和子区域 |
| 05 | 文字编辑 | 空白正文与卡片排版 | 局部字号、颜色、列表、行距、段后距、对齐及行内公式预览 |
| 06 | 表格编辑 | 表格练习 | 导入 Excel／CSV，批量粘贴，调整行列、字号、行高和表格样式 |
| 07 | 公式编辑 | 公式练习 | 插入多子区域公式模块，双击修改 LaTeX、说明和主题色 |
| 08 | 图片与媒体 | 图片与视频练习 | 上传素材，使用原始比例，调整取景、并列等高和14 pt图标题 |
| 09 | 高级对齐 | 高级对齐练习 | 参考线、坐标标尺、网格吸附、单边平移／拉伸及多选等距 |

## 教学操作规则

- 返回教程目录时，每个板块保留本次打开期间的完成百分比；刷新页面，或退出教学后重新进入，所有百分比清零。
- 分项练习只在后台准备前置状态，不会把前置板块误记为用户已完成。
- “代我完成此步”只完成当前一步；“代我完成本项”会完成当前大项的剩余操作。
- 每个新大项从第一步开始，不能跨大项回退；大项内部可以返回上一步。
- 练习步骤中只保留“返回教程目录”，退出入口位于目录页，避免误触。
- 完整教学的最后一步显示全部完成奖励；分项练习的最后一步进入无音效的独立结算弹窗。
- 环形组合、时间轴和多子区域模块均为真实可编辑内容，不是教学截图。
