# 交互教程结构

交互教程位于 `templates/template-1/ustb-blue/tutorial.html`。它以北科科技蓝模板为训练场，每个大项对应一类真实操作；点击顶部“开始教学／继续教学”即可进入。

| 序号 | 教程大项 | 练习页面或入口 | 核心内容 |
| --- | --- | --- | --- |
| 00 | 开始 | 教学首页 | 说明操作方式、进度与跳过规则 |
| 01 | 主题换肤 | 主题与标志 | 将科技蓝逐项调整为钢铁红，替换主题色、浅底和校徽 |
| 02 | 大纲教学 | 文档大纲 | 粘贴三级大纲，生成章节、目录及页面标题 |
| 03 | 页面设置 | 页面信息与备注练习 | 修改标题、章节、页首句、来源、页尾总结和备注 |
| 04 | 模块编辑 | 空白正文与卡片排版 | 插入卡片，调整网格、位置、尺寸、锚点、样式和子区域 |
| 05 | 文字编辑 | 空白正文与卡片排版 | 局部字号、颜色、列表、行距、段后距、对齐及行内公式预览 |
| 06 | 表格编辑 | 表格练习 | 导入 Excel／CSV，批量粘贴，调整行列、字号、行高和表格样式 |
| 07 | 公式编辑 | 公式练习 | 插入多子区域公式模块，双击修改 LaTeX、说明和主题色 |
| 08 | 图片与媒体 | 图片与视频练习 | 上传素材，使用原始比例，调整取景、并列等高和14 pt图标题 |
| 09 | 高级对齐 | 高级对齐练习 | 参考线、坐标标尺、网格吸附、单边平移／拉伸及多选等距 |
| 10 | 环形分布 | 环形文字排版练习 | 实时调整半径和角度；生成后可再次打开并重排原成员 |
| 11 | 时间轴与图文 | 时间轴与图文练习 | 增删、排序时间轴阶段，并切换为普通并列图文卡片 |
| 12 | 备注与放映 | 备注、放映与导出练习 | 页面备注、演讲者视图、全屏放映、保存及 PDF／PPTX 导出 |

## 教学操作规则

- “代我完成此步”只完成当前一步；“代我完成本项”会完成当前大项的剩余操作。
- 每个新大项从第一步开始，不能跨大项回退；大项内部可以返回上一步。
- 教学意外关闭后，可点击顶部“继续教学”恢复到当前大项。
- 环形组合、时间轴和多子区域模块均为真实可编辑内容，不是教学截图。
