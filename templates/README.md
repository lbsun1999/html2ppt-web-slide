# 模板包目录

`templates/`只保存可直接使用的模板包；编辑器、导出器和公共组件仍由项目根目录的`src/`、样式与`server.mjs`统一维护。

当前的`template-1/`是一套共同版式族，包含三种身份／主题变体：

| 模板包 | 用途 |
| --- | --- |
| [ustb-blue](template-1/ustb-blue/) | 北京科技大学科研汇报，科技蓝主题 |
| [ustb-red](template-1/ustb-red/) | 北京科技大学党政汇报，钢铁红主题 |
| [lishui-cyan](template-1/lishui-cyan/) | 丽水学院示例，单一青色主题 |

每个模板包均采用相同的最小结构：

```text
my-template/
├─ template.html       # 内嵌运行时与project-data，可直接双击或拖入工作台
├─ template.json       # 供人和自动化工具识别的说明性清单
├─ README.md           # 主题、素材和使用说明
├─ assets/             # 本模板自带的校徽、照片、来源记录等源素材
└─ output/             # 与该模板对应的PDF/PPTX快照（可选）
```

## 增量添加模板

1. 复制最接近的模板包目录，换一个不会冲突的英文短名。
2. 在复制出的`template.html`中通过工作台修改主题、学校信息、页面和模块，保存回该文件。
3. 只替换新目录自己的`assets/`，同步填写来源；不要改`src/`来登记学校名称。
4. 更新`template.json`与本包README。导出物放在本包`output/`。
5. 直接双击新的`template.html`，或在本地工作台选择／拖入它。HTML已经内嵌公共运行时，不要求核心代码认识这个模板ID。

只有新增通用编辑能力、数据结构或新模块类型时才修改核心代码。单纯新增学校、配色、文稿或素材不应复制一套编辑器，也不应建立长期功能分支。
