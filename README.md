# Web Slide：AI 与人工协作的科研幻灯片工作台

当前稳定版本：**v0.2.0**。

Web Slide 把 AI 内容加工、浏览器人工精修、演讲备注和 PDF／PPTX 交付放在同一份可继续编辑的 HTML 中。AI 可以整理材料和选择版式，用户继续修改文字、公式、表格、图片与模块；保存后的 HTML 还能交回 AI 迭代，不必从头制作。

> ## 主入口：`index.html`
>
> **`index.html` 是项目的主入口、离线导航页和使用说明入口。** 下载并解压后优先双击它，再从图文导航进入主模板、交互教学、说明文档和参考页面。

[![index.html 主入口：模板、说明文档、参考页面与本地服务提示](docs/images/index-navigation.png)](docs/images/index-navigation.png)

`index.html` 将项目内容分成四组，避免用户进入目录后无从下手：

- **主模板**：北科科技蓝、北科钢铁红和丽院青示例；
- **工作台说明**：完整使用说明、AI协作规范和模板扩展接口；
- **学习与参考**：交互式入门、综合示例、文字样式、导航与时间轴；
- **本地服务提示**：需要导出PDF／PPTX时，提示启动方式和访问地址。

## 三分钟开始

1. 下载[完整项目 ZIP](https://github.com/lbsun1999/html2ppt-web-slide/archive/refs/heads/main.zip)，解压到普通本地文件夹。
2. 双击根目录的 `index.html`；GitHub 页面只用于阅读说明，不要直接点击 HTML 源文件。
3. 第一次使用选择“交互式入门教学”；已有经验可直接进入北科科技蓝主模板。
4. 在工作台中先确定文档大纲，再修改页面、模块、文字、图表和备注。
5. 保存 HTML；需要 PDF／PPTX 时运行 [`启动.cmd`](启动.cmd)，在本地工作台中导出。

直接编辑、放映以及导入 XLSX／CSV 均不需要安装环境，双击学校模板 HTML 即可使用。PDF／PPTX 导出、模板重新构建和完整自检需要 Node.js 20.10+、Chrome／Edge及项目依赖；不要求 Microsoft Office 或 Python。

## 核心工作流

```text
原始材料 → AI/人工确认大纲 → 选择现有页面与模块 → 浏览器精修
        → 保存可继续编辑的 HTML → 备注与放映 → PDF/PPTX → 人工终审
```

交互教学使用独立的北科科技蓝训练文稿 `templates/template-1/ustb-blue/tutorial.html`。打开后先进入全屏教程目录：可从头运行原有完整教学，也可直接进入任意分项；进入第 N 项时，系统会在后台重建前 N−1 项完成后的标准状态，再直接落到该板块。每页对应一个教学单元：需要理解空白布局的卡片页与环形页从空白正文开始；表格、公式和媒体页采用“规范示范＋连续练习区”，既可直接编辑成品，也可亲手插入新模块。

[![全屏交互教程目录：完整流程与12个分项入口](docs/images/tutorial-catalog.png)](docs/images/tutorial-catalog.png)

12 个分项覆盖：

1. 手动改成钢铁红主题，并上传独立校徽与组合标志 SVG；
2. 编写、粘贴和应用文档大纲；
3. 修改页面标题、页首句、页尾总结、来源和备注；
4. 在空白页插入卡片，选择固定锚点，调整尺寸和位置，再用网格吸附建立清楚的空白关系；
5. 在表格页直接选中预置表格，离线导入配套 Excel、选择工作表、调整字号／行高／样式，并用 Tab＋回车批量替换数据；
6. 双击公式修改 LaTeX、说明文字与主题色，再练习双子区域图片／视频、原始比例、素材替换和可编辑图标题；
7. 在高级对齐大项中打开一次插件：先把板块左边缘和上边缘平移到参考线，再分别向右、向下拉伸另一侧边缘，最后切换多选模式完成三个板块的水平等距；
8. 在独立的环形分布大项中重新打开插件，复制 4 个单行文本块，通过滑杆实时预览半径和起止角度，确认不越界、不重叠后再生成组合；
9. 将时间轴切换为普通并列图文卡片；
10. 学习多页浏览、演讲者视图、全屏放映与导出。

教程目录为每个分项显示本次打开期间的百分比；返回目录后继续保留，刷新页面或从目录退出教学后重新进入则清零。步骤卡片顶部使用两层“进度标尺”：大圆点表示教学大项，小圆点表示当前大项内的具体步骤；模块编辑、文字编辑、表格编辑和公式编辑分别计为独立大项。已完成、当前和未开始状态用不同主题色区分，并同步显示“第 1.1 步”一类编号。可用“上一步”回看前一条教学说明，已经完成的页面操作不会被擅自撤销。切换步骤时只高亮当前需要操作的控件；教学卡片会根据控件的实时位置自动选择左、右、上、下方的可见空间，窗口或弹窗变化后重新定位。按住标尺区域可手动拖动卡片。操作正确时保留礼花，并由杰瑞配图和“干得真棒”音效反馈；自动完成与跳过本项使用不同的杰瑞／汤姆配图和语音，完整流程全部完成后显示奖杯图并播放本地合成的欢呼掌声。

“代我完成此步”只执行当前操作；“代我完成本项”会依次完成当前大项尚未进行的页面切换、插入、设置和内容填写，不是简单略过。完整流程会继续进入下一大项；分项练习则保留最终页面状态，并打开无音效的奖杯汤姆结算弹窗，从右下角返回目录。分项结算不复用完整教程的杰瑞／汤姆语音或最终欢呼。新的大项从第一步开始，不能跨项返回；到该大项第 2 步后才显示“上一步”。步骤卡片不放“退出教学”，先返回教程目录再退出，避免误触。需要手动上传的钢铁红 SVG 已集中放在 `tutorial-assets/`；表格练习页已经放好唯一一张可编辑表格，可直接导入 `table-import-demo.xlsx`，也可把 `table-replace-demo.txt` 的 Tab／回车文本粘贴到批量编辑框；两种方式均可在离线 HTML 中使用。媒体替换练习素材位于 `tutorial-assets/media/`，教学反馈图片和语音位于 `tutorial-assets/media/sounds/`。

教学进度只保存在当前已打开的教学实例中。返回全屏目录不会丢失各分项百分比；主动退出、刷新页面或关闭后重新进入时，从 0% 开始，避免旧状态与当前练习文稿错位。图片、公式、表格等设置弹窗点击“应用／确定”后，引导会先记录下一步并安全关闭弹窗，不会随弹窗一起消失。

[![分项教程通关后的奖杯汤姆结算页](docs/images/tutorial-section-settlement.png)](docs/images/tutorial-section-settlement.png)

公式、媒体、Excel 工作表选择和表格批量编辑都使用原生设置弹窗。教学卡片会等弹窗真正打开后进入同一顶层弹窗，继续显示下一步说明、高亮目标控件和标准操作反馈，不会在双击公式后突然消失。

高级对齐教学直接高亮真实插件控件，不用文字替代操作，并划分为两个大项。第一个大项打开一次插件，连续完成参考线平移、反向拉伸和多选等距：纵向参考线配合顶部0–1600横坐标，横向参考线切换为左侧0–900纵坐标；先执行左／上平移，再把另一侧向右／向下拉伸，最后直接进入多选并均分间隙。第二个大项是环形分布，切换到环形练习页后重新打开插件，使用数字框与滑杆在真实画布实时预览，只有点击“生成组合”才写入页面。内置练习以 4 个“研究目标”单行文本块、180 px 半径和 −45°～45°窄角度为基准；预览会检查正文安全区与两两重叠，状态合格后再提交。环形组合保留成员身份、顺序、圆心和角度参数；再次选中该组合并点击“环形分布”时进入二次调整，直接重排原成员，不会复制整个组合。

大纲教学固定使用界面中的“更新当前文稿”，保证引导在当前页面中连续运行。工作台中的练习不会自动覆盖磁盘模板；只有主动执行“保存 HTML”才会写入文件，因此原始蓝色模板可反复用于重新教学。界面中的“另建文稿，沿用当前主题”保留给完成教学后的正式建稿，不作为教学中途步骤。

大纲既可直接粘贴，也可导入 `.md`／`.txt` 文件。文件内容载入后教学会自动进入应用方式说明；即使提前点击“应用到当前文稿”，引导也会保留并继续进入下一大项，不随大纲弹窗关闭。

## 放映、备注与导出

### 两种正式放映方式

- **演讲者视图**：适合投影仪或第二块屏幕。观众窗口只显示画面，工作台保留当前页备注并同步翻页；窗口由用户拖到目标屏幕。
- **全屏放映**：适合单屏。方向键或滚轮翻页，双击进入总览；Ctrl＋滚轮缩放，放大后左键拖动；Esc 第一次复位、再次退出。

[![全屏放映画面与操作提示](docs/images/presentation-fullscreen.png)](docs/images/presentation-fullscreen.png)

工作台另有单页、单列滚动和可指定列数的多页滚动视图，用于制作与检查，不等同于正式放映。点击“页面备注”后，备注作为工作台底部的独立停靠区显示，不再排到全部页面之后；单列滚动停到另一页时，备注随当前页自动切换，多页视图则以用户明确点击选中的页面为准。

### 本地导出

Windows 双击 [`启动.cmd`](启动.cmd)，或在项目目录运行：

```powershell
node scripts/start.mjs --open
```

服务启动后访问 `http://127.0.0.1:4317`，选择“打开 HTML”，再导出到指定路径。无需拖拽文件。遇到 Windows 来源提醒、启动闪退、缺少依赖或端口占用时，查看[启动与导出排障](docs/启动与导出排障.md)。

[![离线 HTML 连接本地导出服务](docs/images/local-export-connection.png)](docs/images/local-export-connection.png)

> **PPTX 必须人工逐页审核。** 导出结果已尽量保持标题单行、手动换行、中文标点规则、列表、页脚和参考文献顶端对齐，但不同 PowerPoint 环境仍可能出现字体替代、局部颜色或标点断行差异。

## 维护与验证

恢复依赖并启动服务后运行：

```powershell
npm.cmd ci
npm.cmd run test:all
```

测试日志写入 `ect/self-check/`。自动检查覆盖结构、边界、编辑、主题、公式、表格、时间轴、放映和导出，但不能替代逐页目视检查和真实 PowerPoint 环境终审。
